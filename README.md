# Online Book Store Database Project

## Project Overview
This project is a PostgreSQL-based Online Book Store Database Management System designed to manage books, customers, orders, and sales records efficiently.

The project demonstrates SQL concepts such as:
- Database creation
- Table relationships
- CRUD operations
- Joins
- Aggregate functions
- Group By clauses
- Order management queries

---

## Technologies Used
- PostgreSQL
- SQL
- DBeaver

---

## Features
- Manage book records
- Store customer information
- Track orders and sales
- Retrieve sales reports
- Perform SQL queries for analysis

---

## Database Tables
- Books
- Customers
- Orders
- Authors
- Categories

---

## Sample SQL Operations
- SELECT queries
- JOIN operations
- GROUP BY queries
- Aggregate functions
- Filtering using WHERE clause
